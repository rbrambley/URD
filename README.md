 # UDisc Round Dashboard Generator
 
 A web application to upload and analyze UDisc round data from CSV files.
 
 ## Features
 
 - Upload CSV file exported from UDisc
 - Generate dashboard with statistics like total rounds, average score, etc.
 
 ## How to Use
 
 1. Open the web app.
 2. Click "Choose File" to select your UDisc CSV.
 3. Click "Analyze File" to view the dashboard.
 
 ## Hosting on GitHub Pages
 
 1. Create a new repository on GitHub.
 2. Push these files to the repository.
 3. Go to the repository settings.
 4. Under "Pages", select the main branch as source.
 5. The site will be available at `https://<username>.github.io/<repo-name>/`
 
 ## Technologies Used
 
 - HTML, CSS, JavaScript
 - PapaParse for CSV parsing
